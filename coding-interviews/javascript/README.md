# JavaScript Coding Interview Problems

Status: index only — each problem's full write-up (starter code, solution, follow-ups) is
added when you pick it to work on. See [`coding-interviews/README.md`](../README.md) for the
format. These are framework-free and pair naturally with
[ch.00](../../notes/00-javascript-and-browser-fundamentals/README.md).

## Problem list

1. `debounce(fn, delay)`
2. `throttle(fn, delay)`
3. Deep clone an object (without `structuredClone`)
4. Deep equality check
5. `memoize(fn)`
6. `curry(fn)`
7. `compose(...fns)` / `pipe(...fns)`
8. Implement `Promise.all`
9. Implement `Promise.race`
10. `retry(fn, attempts)` with backoff
11. Async concurrency limiter (run N promises at a time)
12. Simple event emitter / pub-sub
13. LRU cache
14. Flatten a nested array
15. Flatten a nested object (dot-path keys)
16. Deep merge two objects
17. Rate limiter
