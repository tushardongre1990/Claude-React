# Master Revision Notes

A single place to do a fast, full-syllabus pass before an interview, instead of opening all
18 chapter folders individually. Each chapter writes a short cheat sheet to its own
`revision.md` when that chapter is completed — this page just indexes them in order, with a
one-line summary of what to expect.

**How to use this before an interview:** start at the top, skim each linked `revision.md` in
order. They're written to be re-readable in 5-10 minutes per chapter, not full explanations —
if something doesn't click, go back to the full chapter `README.md` for the explanation.
