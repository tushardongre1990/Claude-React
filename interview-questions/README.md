# Interview Questions

Short-form interview material that's distinct from both the chapter notes (`notes/`) and the
implementation problem bank (`coding-interviews/`) — this is about *reading and reasoning
about* code and scenarios, not building things.

- [`explain-this-output/`](explain-this-output/README.md) — short React/JS snippets where the
  question is "what gets logged/rendered, and why?" Excellent for testing whether
  understanding is real or copy-pasted.
- [`react-traps/`](react-traps/README.md) — a catalog of common misconceptions and gotchas
  (rendering, effects, state, performance, keys, context) — the things that sound right but
  are subtly wrong.
- [`debugging-scenarios/`](debugging-scenarios/README.md) — open-ended production scenarios
  ("users report the page is slow", "this only breaks in production") that test debugging
  process, not just API (Application Programming Interface) knowledge.

As with everything else in this repo, entries are added when explicitly worked on, not
pre-written in bulk. See [`/CLAUDE.md`](../CLAUDE.md).
