**Status:** Not Started

## Why this chapter matters for a 5-10 YOE interview
Knowing when *not* to reach for a ref is as important as knowing the API — a common signal of seniority.

## Topics to cover

- useRef for mutable values vs actual DOM references
- React 19: ref as a plain prop (no more forwardRef) + ref cleanup functions
- useImperativeHandle and when it's actually justified
- Portals: modals, tooltips, and other escape-the-DOM-tree use cases
- Measuring DOM nodes, focus management
- Avoiding ref overuse — when state or derived data is the right tool instead

## What you'll build
A modal (via portal) with focus trapping, plus a custom input exposing an imperative focus() method.
